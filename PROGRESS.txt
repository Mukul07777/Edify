1.5 Innovation #1 - Root-cause gap tracing  .................... DONE
    Problem: a student "fails Rotational Motion" but the real gap is
    Class 7 ratios or Class 10 trigonometry. Nobody finds that.
    - Student picks a chapter -> AI builds a chain of real earlier
      chapters, going down through the classes (JEE/NEET -> Class 10 ->
      Class 7...). Invented chapters and bad questions are dropped.
    - One quick check question per link -> the deepest wrong answer is
      the ROOT gap.
    - 5-minute fix lesson in the student's language + a re-check
      question -> marked "fixed".
    - Chains and lessons are shared/cached: the next student with the
      same gap costs zero AI.
    - Coach puts "Fix the root" first in the daily plan.
    - New page: /app/roots ("Root cause" in the menu).
    - Live-tested with the real AI:
        JEE Rotational Motion   -> Class 10 trigonometry
        NEET Electrostatics     -> Class 7 signed integers
        Class 10 Trigonometry   -> Class 7 ratios
